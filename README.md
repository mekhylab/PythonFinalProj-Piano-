Piano Dash (Python / Pygame)

Piano Dash is a rhythm-based piano clicking game built in Python using Pygame, inspired by the popular Piano Tiles game.

Main source code: piano.py

Technologies:

Python
Pygame
Object-Oriented Programming
Event-driven game loop
File I/O for persistent data storage

Features:
Interactive rhythm gameplay with mouse and keyboard input
Multiple difficulty levels with increasing speed
Dynamic difficulty scaling based on player score
Persistent high-score tracking stored locally
Sprite-based tile system and sound effects

How to Run:

pip install pygame
python piano.py

GitHub’s language statistics may show HTML due to large asset files, but all core game logic and mechanics are implemented in Python within piano.py.
